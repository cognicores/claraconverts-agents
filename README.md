# ClaraConverts plugin for Claude

Add Clara to any website: an AI conversion agent (voice and text chatbot) that visitors talk to in 10 languages, and that turns them into customers. The plugin has the install Skill and the ClaraConverts MCP server (`https://claraconverts.com/mcp`).

No API key is needed to connect, see pricing, list integrations, or create a free trial.
